- ❌ Свечи, фильтры, ремни, масла, расходники
- ❌ Турбины, ТНВД, форсунки, инжекторы
- ❌ Подвеска, тормоза, рулевое
- ❌ Кузовщина, оптика, салон
- ❌ Электрика, датчики, ЭБУ
- ❌ Запчасти для НЕ-японских машин (немцы, корейцы, америка — мимо)

Если запрос вне нашей ниши — направляй на конкурентов или говори честно
«у нас только капиталка моторов японцев».

## Как покупатель покупает (важно для UX)

1. Заходит из Google по запросу типа «поршни 1KZ Алматы» / «кольца 4D56 цена»
2. Попадает на страницу мотора или конкретного SKU
3. Видит: бренды, размеры (STD, 0.25, 0.50, 0.75, 1.00), наличие (зелёная ●)
4. Жмёт «Узнать цену в WhatsApp» → открывается prefilled-сообщение
5. Семён отвечает с ценой и наличием

**Цен на сайте НЕТ.** Указано только «от 15 000 ₸» для поршней (для Google rich-snippet).
Не добавляй цены без явного запроса.

## Структура URL (важно при добавлении страниц)

```
/                                                    — главная
/{brand}/                                            — бренд (toyota, nissan, ...)
/{brand}/dvigateli/{engine}/                         — лендинг мотора (1kz, 2jz, ...)
/{brand}/dvigateli/{engine}/porshni/                 — листинг поршней мотора
/{brand}/dvigateli/{engine}/porshni/{product}/       — SKU (бренд × вставка × размер)
/{brand}/dvigateli/{engine}/koltsa-porshnevye/       — листинг колец
/{brand}/dvigateli/{engine}/vkladyshi/               — листинг вкладышей
/zapchasti/porshni/                                  — общий лендинг поршней
/brendy/{brand}/                                     — лендинг бренда запчастей
```

Slug-правила: `lib/slugs.ts`. Меняешь slug → ломаешь индексацию Google.

## Что было сделано с сайтом (хронология PRs)

### Фаза 1: запуск (май 2026, PR #1–9)
- Google Ads: 53 объявления, 8 sitelinks, ключи только Exact match
- SEO-оптимизация страниц мотора и категорий
- GA4 (`G-YQ21411TM0`) + Google Ads conversion `AW-18062973221`
- `sendBeacon` для гарантированной доставки событий при уходе на WhatsApp
- Создание per-SKU страниц: каждый артикул TEIKIN × размер = отдельная страница

### Фаза 2: контент и каталог (PR #10–16)
- Редизайн карточки товара: чистая каталожная картинка, русские термины
- Объяснения суффиксов A / G / AG (ALFIN, oil gallery)
- Компактная above-the-fold + раскрывающиеся блоки
- Реальные фото товара и упаковки TEIKIN
- Скрейпер TEIKIN: 176 моторов получили официальную картинку + PDF-данные
  (диаметр, объём, OEM номера) → автогенерация `teikin-catalog-auto.ts`
- Миграция с Render на **Supabase** (PostgreSQL session pooler)
- Удалены лишние данные (диаметр пальца, пин-номера), скрыты дизельные размеры,
  которых нет в продаже (только STD и 0.50 для дизелей)

### Фаза 3: customer flow (PR #17–22)
- Связали листинг с per-SKU страницами (раньше были «висящие в воздухе»)
- Поиск по сайту + prefilled WhatsApp-сообщения
- SEO-лонгриды для брендов и категорий
- Product Schema с `lowPrice: 15000 ₸` для Google rich-snippet
- Yandex Webmaster verification
- Документация: [CLAUDE.md](CLAUDE.md), [PLAYBOOK.md](PLAYBOOK.md), [DEPLOY.md](DEPLOY.md)

### Фаза 4: оживление (PR #23 — текущий)
- Hero на главной с framer-motion: word-stagger spring, magnetic CTA,
  mesh-gradient параллакс, spring counters, scroll-progress bar
- Лёгкие CSS-анимации на страницах поршней (mobile-first):
  - stagger fade-up на карточках товара
  - пульсация зелёной точки «● в наличии»
  - tap-press (scale 0.97) на всех CTA и тапаемых карточках
- React+framer-motion грузятся **только на главной** (~110KB gz).
  Все 1548 других страниц = 0 JS файлов, только inline IntersectionObserver
- Дизайн-токены из UI UX Pro Max skill: палитра #52 (Automotive) +
  font pairing #3 (Tech Startup: Space Grotesk + Inter)

## Что НЕ делать без явного спроса владельца

- ❌ Не публиковать цены кроме «от 15 000 ₸» на поршнях
- ❌ Не менять `--c-red #E50914` (брендовый цвет)
- ❌ Не трогать slug-структуру URL (Google проиндексировано)
- ❌ Не править данные в БД через миграции (БД управляет владелец)
- ❌ Не пересоздавать `teikin-catalog-auto.ts` руками (AUTO-GEN из PDF)
- ❌ Не добавлять категории товаров вне капиталки двигателя
- ❌ Не коммитить без подтверждения
