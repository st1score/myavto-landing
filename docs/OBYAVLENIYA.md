# Как добавить объявление в «Продаю своё»

Без кода, прямо в GitHub с телефона или компьютера.

1. Фото: откройте папку `public/prodazha/` → **Add file → Upload files**. Создайте папку с именем
   объявления латиницей, например `public/prodazha/zima-225-65-r17/`, и загрузите 3–10 фото
   (JPG, по возможности до 500 КБ каждое, горизонтальные 4:3).
2. Текст: откройте `src/content/prodazha/` → **Add file → Create new file**, имя файла —
   то же, что у папки с фото: `zima-225-65-r17.md`. Вставьте шаблон и заполните:

```md
---
title: "Зимние шины Bridgestone Blizzak 225/65 R17, 4 шт"
type: shiny            # shiny — шины, diski — диски, raznoe — разное
price: 120000          # цена в тенге, только цифры
condition: "Б/у"
status: v-prodazhe     # когда продали — поменяйте на prodano
date: 2026-11-21       # дата публикации
photos:
  - /prodazha/zima-225-65-r17/1.jpg
  - /prodazha/zima-225-65-r17/2.jpg
specs:
  Размер: "225/65 R17"
  Сезон: "Зима, шипы"
  Год: "2022"
  Остаток протектора: "7 мм"
---
Короткое описание: откуда, состояние, почему продаёте.
```

3. Нажмите **Commit changes**. Через 1–2 минуты объявление появится на сайте и на главной.

Продали — поменяйте `status: v-prodazhe` на `status: prodano`. Страница 30 дней покажет «Продано»
(без индексации), потом пропадёт сама. Файл можно удалить позже.

Для дисков в `specs` удобно указать: Диаметр, Ширина (J), Сверловка (PCD), Вылет (ET), Ступица (DIA), С какой машины.
