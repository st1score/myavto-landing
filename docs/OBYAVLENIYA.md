# Как выставить объявление (шины, диски, другое)

Адрес админки: **https://my-avto.kz/admin/** — работает с телефона и компьютера.

## Один раз: получить ключ для входа

1. Зайдите на GitHub под своим аккаунтом (тем, где лежит сайт).
2. Откройте https://github.com/settings/personal-access-tokens/new
3. Заполните:
   - **Token name**: `my-avto admin`
   - **Expiration**: `No expiration` (или 1 год)
   - **Repository access** → **Only select repositories** → `st1score/myavto-landing`
   - **Permissions → Repository permissions → Contents** → `Read and write`
4. Нажмите **Generate token** и скопируйте длинную строку `github_pat_…`.
5. Откройте https://my-avto.kz/admin/ → **Sign In with Token** → вставьте строку → войти.

Браузер запомнит вход. Ключ никому не отправляйте: с ним можно менять сайт.
Чтобы войти с телефона, уже войдя на компьютере: меню аккаунта (справа вверху) → **Sign In with Mobile** → отсканировать QR.

## Новое объявление

1. **Объявления → New / Создать**.
2. Выберите, что продаёте: шины, диски, колёса в сборе или другое.
3. Загрузите фото (первое — главное). Сайт сам их уменьшит.
4. Цена в тенге, количество, состояние.
5. Для шин: сезон, ширина/профиль/диаметр, производитель, модель, год, остаток протектора.
   Для дисков: тип, диаметр, ширина J, сверловка (5x114.3), вылет ET, ступица DIA.
6. Заголовок можно не писать — сайт соберёт сам, например
   «Зимние шины Bridgestone Blizzak 225/65 R17, 4 шт». Для «Другое» заголовок нужен.
7. **Save / Сохранить**. Через 1–2 минуты объявление будет на сайте: в разделе
   https://my-avto.kz/prodazha/, на главной и в карте сайта для Google и Яндекса.

## Продали

Откройте объявление → **Статус: Продано** → Сохранить. 30 дней на странице будет плашка
«Продано» (Google её не индексирует), потом объявление само исчезнет с сайта.

## Без админки (на всякий случай)

Объявление — это файл `src/content/prodazha/<имя>.md`, фото лежат в `public/prodazha/`.
Поля те же, что в админке (см. `public/admin/config.yml` и `src/content.config.ts`).
