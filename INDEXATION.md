# Индексация my-avto.kz — пошагово

> Цель: завести сайт в Google + Яндекс, чтобы товарные страницы начали
> появляться в органике. Порядок важен. Делать сверху вниз.

## Предусловие (без этого пункты ниже бессмысленны)

Ветка `claude/seo-hardening` смержена в `main` и задеплоена → на проде живут:
- `https://my-avto.kz/sitemap.xml` (10 URL: главная, поиск, 8 товаров)
- `https://my-avto.kz/robots.txt` (ссылается на sitemap)
- `https://my-avto.kz/feed.xml` (Google Merchant фид)
- JSON-LD `Product`/`LocalBusiness` на страницах

Проверить, что sitemap реально открывается в браузере, ПРЕЖДЕ чем продолжать.

---

## 1. Google Search Console (GSC) — главный канал

1. https://search.google.com/search-console → Add property → **URL prefix** →
   `https://my-avto.kz`.
2. Способ верификации → **HTML tag** → скопировать значение `content="..."`
   (только сам токен, без тегов).
3. Положить токен в GitHub → Settings → Secrets and variables → Actions →
   New secret: `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` = `<токен>`.
4. Перезапустить деплой (Actions → Deploy → Run workflow) → дождаться.
5. В GSC нажать **Verify**.
6. GSC → **Sitemaps** → добавить `sitemap.xml` → Submit.
7. GSC → **URL Inspection** → вставить URL главной → **Request indexing**
   (ускоряет первый обход). Повторить для 2-3 топ-товаров.

> Альтернатива верификации без секрета: в GSC выбрать «HTML file», скачать
> `googleXXXX.html`, положить в `web/public/`, закоммитить, задеплоить.

---

## 2. Яндекс.Вебмастер — критично для KZ

Яндекс в Казахстане значим. Делать обязательно.

1. https://webmaster.yandex.ru → Добавить сайт → `https://my-avto.kz`.
2. Верификация → **Мета-тег** → скопировать значение `content`.
3. GitHub Actions secret: `NEXT_PUBLIC_YANDEX_VERIFICATION` = `<токен>`.
4. Перезапустить деплой → в Вебмастере нажать «Проверить».
5. Вебмастер → **Индексирование → Файлы Sitemap** → добавить
   `https://my-avto.kz/sitemap.xml`.
6. Вебмастер → **Переобход страниц** → добавить главную + товары.
7. Указать **регион сайта** = Алматы (Вебмастер → Информация о сайте → Регион).

> Альтернатива: «HTML-файл» → `yandex_XXXX.html` в `web/public/` → коммит → деплой.

## 3. Google Business Profile (GBP) — быстрый локальный трафик

Самый быстрый РЕАЛЬНЫЙ трафик в Алматы (дни, не месяцы). Бесплатно.

1. https://business.google.com → создать профиль.
2. Название: **MY AVTO**. Категория: «Магазин автозапчастей».
3. Адрес: ТЦ CarCity, 3 ярус, бутик 135В, Алматы. Телефон: +7 701 550-93-77.
   Сайт: https://my-avto.kz. Часы: Пн–Сб 9–17, Вс 11–16.
4. Подтвердить (открытка/телефон/видео).
5. Загрузить фото точки, товара, логотип. Добавить WhatsApp.

> Данные ДОЛЖНЫ совпадать с `LocalBusiness` JSON-LD на сайте (имя/адрес/телефон/
> часы) — Google сверяет. Источник в коде: `web/lib/seo.ts`.

## 4. Google Merchant Center — бесплатные товарные показы

1. https://merchants.google.com → создать аккаунт (страна: Казахстан, валюта KZT).
2. Подтвердить сайт (через связанный GSC — автоматически).
3. Products → Feeds → добавить feed по URL: `https://my-avto.kz/feed.xml`,
   расписание обновления — ежедневно.
4. Включить **Free listings** (включены по умолчанию) — товары пойдут в Shopping
   бесплатно, без рекламы.
5. (Позже, для рекламы) Performance Max / Shopping кампания на этот же фид.

---

## 5. После индексации — что мониторить

- GSC → **Pages**: сколько URL проиндексировано (цель — все из sitemap).
- GSC → **Performance**: показы/клики по запросам → видно, под что ранжируешься.
- Merchant → **Products**: одобрены/отклонены (чинить отклонённые — нет фото/цены).
- Вебмастер → **Поисковые запросы**.

+ лендинги-хабы (категория/двигатель). Это следующий шаг после индексации.
